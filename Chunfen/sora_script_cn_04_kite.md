# 春分 · 04 放风筝（仅审阅，纯画面）

时长：约50秒。输出：无屏幕文字、无音频。机位克制。
全局连贯性：复古黄纸 + 墨波纹转场；右侧暖侧光；风向右→左。

0s — 黄纸铺满。墨波纹揭示：河岸草甸与新生草、垂柳。传统燕子与长龙风筝待飞。保持地平稳。

6s — 低角仰望天空：风筝起飞；轮线拉紧。软积云飘移；右侧轮廓光勾形体。

12s — 近景手部操作线轴；指关节、木制线轴的纹理、线的颤动。无文字。

18s — 风筝继续升高；远处孩子指向；柳条向左摆示风向。

24s — 游走云影短暂柔化光线后复原；温和维持曝光。

30s — 空中跟拍风筝，极小幅平摇（≤10°）。让线条穿越画幅形成纵深。

36s — 短切：草尖向左弯；一条纸飘带飞舞。

42s — 风筝在高空稳定；蓝天加深；一只小鸟穿行。保持宁静。

46s — 转场：墨波纹收回至黄纸。黄纸纹理停留2秒以便拼接。

48s — 停留黄纸画面，稳。
