# 春分 · 临时方案（可行性验证，Sora仅画面 + 后期剪映）

目标与总时长
- 目标：围绕“春分”集中创作，覆盖6–8分钟；本方案提供8个习俗，每个约50秒，总计约6分40秒（400s）。
- 工具规则：Sora仅生成画面（无声无字）；配音与字幕由剪映AI后期生成；Midjourney用于关键帧统一风格与衔接。

习俗清单（8×≈50s ≈ 6:40）
1) 春分祭日（象征性日祭、祈和合）
2) 春社祈谷（社日祭土、踏社仪式）
3) 竖蛋（昼夜平分·立蛋求顺）
4) 放风筝（扶摇送旧疾）
5) 踏青赏花（郊原行乐）
6) 春分吃春菜（岭南春菜汤/荠菜）
7) 迎燕护巢（玄鸟至·护巢惜燕）
8) 育秧整畦（南方早稻育秧、拱棚保温）

目录结构
- `sora_script_en_*.md`：每个习俗一份，单段脚本，时间轴从0秒开始（visuals-only）。
- `midjourney_prompts.md`：8个习俗的双语关键帧提示（首/中/尾），统一风格参数。
- `voiceover_cn.md`：对应旁白文本（后期剪映用），含建议时间点。
- （可选）后续可按需生成各习俗的 SRT 文件或合并字幕稿。

统一风格与物理逻辑
- 画幅：16:9；时长：每段≈50s；风格：复古黄纸版 + 水墨写意，半写实细节。
- 光线：清晨或傍晚侧光（默认右侧入射）；风向：右→左，阴影与风雨/烟/纸带运动一致。
- 转场：黄纸+墨波纹 reveal / retract；每段从黄纸开场，到黄纸收束，便于拼接。
- 文本与音频：生成时忽略；脚本内出现的文字/配音仅为后期参考。

生产建议
- 先用 `midjourney_prompts.md` 生成每段的首/中/尾关键帧，校准风格、构图与色温。
- 用 `sora_script_en_*.md` 分别投喂 Sora（每次一个习俗），生成无声画面。
- 在剪映中用 `voiceover_cn.md` 作为配音与字幕素材，统一音色与字样。

总时长校验
- m=8 个习俗，n≈50 秒/习俗 ⇒ m×n≈400s ≈ 6分40秒；可再加30s开篇、50s收束，扩展到≈8分。
