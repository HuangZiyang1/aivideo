# 春分 01 · 春分祭日（分段投喂与拼接说明）

分段方案（总≈50s）：15s + 15s + 10s + 10s
- 01A (15s)：开场/供品/系绸带，稳态建立与风向确认
- 01B (15s)：点香/稽首/香尖微距与烟羽
- 01C (10s)：三鞠躬节律+草编日轮（轻随动）
- 01D (10s)：回到供品金光/烟层/燕影，小结与收束

Sora 投喂要点（每段均从 0s 开始，visuals-only）
- 每段脚本都以“黄纸铺满→墨波纹揭示场景”开场，并在末尾“墨波纹收束→黄纸停2s”。
- 若你要把4段拼成一支≈50s成片：在剪辑时“保留第1段开场的黄纸”和“保留第4段结尾的黄纸”，中间两处转场可剪掉黄纸段（或用黄纸作自然分章）。
- 机位克制：大多锁三脚架或极小幅随动；风向统一右→左；光位统一右侧清晨暖侧光。

Midjourney 使用建议
- 先用 `midjourney_prompts_01_split.md` 生成每段的开/中/收三张关键帧，校准构图、色温、材质（黄纸肌理、烟、薄雾、木与铜）。
- 如果Sora支持参考图，可把关键帧作为参考；否则在后期作为风格标尺对照。

拼接与声音（参考）
- 全片应无机内字幕与音频；配音与字幕走剪映AI后期。
- 统一“黄纸+墨波纹”作为段间分章语言，便于跨项目风格保持。
