# 立春（完成品规格）

- 架构：一个节气包含 1–2 个习俗；本节气选取「鞭春牛」「咬春」。
- 时长：每习俗 10s；每习俗 3 句中文旁白，对应 3 个分镜。
- 视觉：复古黄纸版 + 水墨浸染；古风场景；无校服/校徽元素。
- 工具：
  - Midjourney：用于静态关键帧（首、中、尾）— 见 `midjourney_prompts.md`。
  - Sora：用于视频生成 — 见 `sora_scripts_en.md`（英文详细时序与物理逻辑）。
  - 旁白文本：见 `voiceover_cn.md`，可在后期配音。

## 文字处理原则（重要）
- 最终政策：Sora 仅生成无声、无字的画面，所有片内文字（标题、节气名、习俗名、字幕）与中文配音一律在后期用剪映 AI 完成。
- 脚本中出现的“文本意图”（如“Lìchūn”或小楷说明）仅作为占位语义，投喂 Sora 时请忽略文本，让其只生成画面。
- 若需要统一风格的文字，请在剪辑软件中使用一致的字体、描边与入出动画。

## 使用建议
- 生成关键帧后，将 `sora_scripts_en.md` 按分镜分段投喂给 Sora（每习俗 3 段或整段 10s），转场统一用 ink-ripple，保持连续性。
- 音频与字幕：全部在剪映 AI 后期完成；Sora 如有音频输出请静音或舍弃。
- 两个习俗拼接后，即构成「立春」完整片段（约 20s）。
