# 段 D — 11s — 队列前行；图纸张贴（纯画面）

目标：街口队列前行与室内张贴图纸交替呈现；最终定格于张贴完成的图纸。

全局设置
- 风格：复古半写实；清晨，与段A保持连续。
- 环境：街口中广景（旗帜、绸带）；室内木质板面，浆糊新沾。
- 镜头：街口中广景与室内中景硬切交替；三脚架稳定；各镜头曝光/对焦锁定；无甩镜。
- 物理：右侧光；风向右→左；浆糊先亮（高光≈0.25）后哑（<0.05）；纸角归稳。
- 安全（画面）：避免切换间画面形变；阴影方向一致；无转场特效。
 - 连续性/文本：服饰与旗帜色值延续A/B；定格图纸需清晰可辨“春牛图”三字（位于画心上三分之一处），字形为木刻风格。

时间线（0.0–11.0s）
0.0–4.8s（街口中广景）：队列前行；令旗摆动周期≈1.3s；袖摆幅度中等；保持视差但机位无漂移。
4.8–8.6s（室内中景）：农人抹浆糊；可见涂抹纹理；定位图纸；沿边压实；纸角约1.5s内归稳；轻风短促撩动后阻尼。
8.6–11.0s（定格图纸）：最后定格于已张贴图纸；“春牛图”三字清晰可读；浆糊高光下降；纸面平整；风效应可忽略；干净收尾。
