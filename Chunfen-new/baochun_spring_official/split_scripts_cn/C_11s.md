# 段 C — 11s — 检视与安放图纸（纯画面）

目标：室内以微距清晰检视“春牛图”，随后准备安放；无文字/无配音。

全局设置
- 风格：复古半写实；简素木案或门口长凳；室内低调。
- 环境：亚光木质表面；背景为时期器物（陶碗、竹篮）柔焦；避免现代装饰。
- 镜头：微距/近景；锁定曝光；手动对焦约30–40 cm；硬切；无拉焦。
- 物理：右侧光；微风令近侧纸角抬升约5–10 mm；阴影一致落左。
- 安全（画面）：避免微闪烁；无塑料质地高光；避免过度锐化光晕。
 - 连续性/文本：服饰与段A/B保持一致；图纸上必须可见中文“春牛图”三字（木刻字形），笔画完整；禁止英文替代。

时间线（0.0–11.0s）
0.0–2.8s（微距）：图纸平铺；画心上方清晰可见“春牛图”三字；墨色微光泽（≈0.15）；木刻略有起伏；机位低角度捕捉高光。
2.8–5.5s（近景）：硬切至孩童探看；目光跟随图纸；背景器物柔焦；保留头顶留白；表情不夸张。
5.5–8.7s（近景）：切回图纸；农人以布擦净指缝；清除泥丝；可见布纤维；指尖轻触纸角。
8.7–11.0s（微距/停）：近侧纸角抬升5–10 mm；轻微摆动；最后一帧稳定；无转场干净收尾。
