# 段 B — 15s — 叩门并递交春牛图（纯画面）

目标：以触感真实的细节呈现礼敲与薄纸木刻“春牛图”的交接。

全局设置
- 风格：复古半写实；清晨右侧暖光；柔和阴影。
- 环境：旧木门与铁门环；农人方自田作归来；避免现代锁具/亮漆。
- 镜头：硬切中景→近景；三脚架稳定；各镜头曝光/对焦锁定；突出手部与纸纤维。
- 物理：风向右→左；纸边翘起角度12–18°；开门瞬间室外光由门缝推进（照度变化ΔEV≈0.7），落在农人颧骨/眉骨形成明暗分界；微尘向内侧缓慢漂移；阴影统一落左。
- 安全（画面）：避免塑料般高光；无稳定器拉伸伪影；硬切间曝光不跳变。
 - 服饰/人物（细化）：春官官袍暗绛缎面、云肩与“春牛牧童”绣团纹可辨；乌纱小翼冠；随行执旗者与小鼓手在背景浅虚化掠过（不喧宾）。农人着粗布短衣，袖口/指背有泥痕与干裂纹路；“灰头土面但精神抖擞”。
 - 文本/提示（Sora）：本段出现的纸张文字务必为中文汉字“春牛图”三字，字形完整、笔画不缺失，禁止英文或拼音替代；请严格渲染为木刻印刷风格汉字。

时间线（0.0–15.0s）
0.0–3.0s（中景）：春官礼敲；展现手腕/指节动作；门板轻颤；微尘抖落。
3.0–6.5s（近景）：由内侧闩动开始；门从内向外开启一掌→两掌宽，外界暖光缓慢推进；农人探身至门缝，面部与衣襟带尘，但眼神明亮有神；动作为拉闩/推门（手背泥痕、指节开合与木门触点可辨），无无意义“手指弯曲”。
6.5–11.5s（近景）：春官呈上木刻薄纸——画幅上方清晰可见“春牛图”三字（木刻印刷字形，字距均匀）；可见纸纤维与毛边；边缘随风轻翘（周期≈1.2s）。
11.5–15.0s（中近景）：双手郑重交接；拇指托住下缘；避免纸面起褶；阴影连贯；在握稳瞬间干净收尾。
