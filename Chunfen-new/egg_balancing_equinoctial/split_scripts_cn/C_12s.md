# 段 C — 12s — 校验：轻呼气与阴影（纯画面）

目标：以轻呼气或微风验证稳定；阴影几何不显著改变。

全局设置
- 风格：复古；纹理克制、无现代塑料；亚光材质。
- 镜头：微距；对焦20–28 cm；硬切；曝光锁；无变焦；白平衡稳定。
- 物理：近午顶光；阴影1–2 cm且直；轻呼气引起摆幅≤1°、周期≈0.8–1.2 s；风右→左0.2–0.3 m/s仅动布边；接触斑保持居中。
- 禁止：防抖形变、自动追焦；手部进入画面。

时间线（0.0–12.0s）
0.0–3.5s：手撤离；阴影短直清晰。
3.5–8.0s：一次极轻呼气；鸡蛋摆幅≤1°、周期≈0.8–1.2 s后快速回稳。
8.0–12.0s：回稳定格；阴影长度/方向不变；画面静止收尾。
