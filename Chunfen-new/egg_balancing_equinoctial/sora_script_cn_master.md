# 春分 · 立蛋（近午顶光）— 母版 ~48s，纯画面

目标（最终策略）：约48秒母版参考（生成阶段静默、无屏幕文字）。按四段生成（12s + 12s + 12s + 12s）。不使用入/退场特效；分镜之间硬切。风格复古；物理遵循真实光/风/阴影。本习俗将光源改为近正午顶光，以符合春分立蛋的实践。

全局设置
- 画幅：16:9；总时长：约48秒。
- 风格：复古半写实；素净亚光桌面；低饱和；器物细微包浆；无高光镜面反射。
- 环境：简素院落/桌面；时期陶碗/素布；木纹节距≈2–4 mm；布纤维可见（≈0.2–0.4 mm）；避免现代塑料/亮光漆。
- 镜头：三脚架稳定；曝光锁定；固定对焦；微距≈15–40 cm；无变焦/拉焦/自动构图；仅硬切；白平衡稳定；避免数码锐化晕圈。
- 光与风：近午顶光；物体下短直阴影（≈1–2 cm）；风右→左（0.2–0.3 m/s）仅轻推布边；阴影极短但保持一致；无热空气扭曲。
- 安全：无入退场特效；避免对焦 hunting/曝光脉动；避免稳定器形变；手部动作轻柔。
- 文本与配音：生成阶段忽略（纯画面）；时间点供后期参考。

时间线与分镜（0.0–48.0s）
0.0–12.0s（段 A —— 准备：鸡蛋与桌面）
- 画面：摆放白胖鸡蛋；检查木纹节距≈2–4 mm；选平整处；素布擦拭可见纤维；确认短直阴影。
- 机位：近景/微距；对焦20–30 cm；曝光锁定；硬切；避免防抖形变。
- 物理：顶光短阴影≈1–2 cm；风0.2–0.3 m/s轻推布边；阴影方向稳定直线；尘埃极少且静止。
- 细节：避免现代印刷；桌面亚光；蛋壳可见天然细孔。

12.0–24.0s（段 B —— 指尖轻旋与尝试平衡）
- 画面：指尖轻旋鸡蛋；出现微小摆动；寻找平衡；接触斑清晰微小；短暂放手观察。
- 机位：微距聚焦接触点；对焦15–25 cm；曝光锁定；无拉焦；画面构图稳定。
- 物理：接触斑直径≈3–5 mm；摆幅≈2–4°，周期≈1.2–1.6 s；约2 s内阻尼至≤1°；风量极小。
- 细节：指甲自然；无饰品；避免指尖遮挡接触斑。

24.0–36.0s（段 C —— 达成立蛋）
- 画面：鸡蛋直立；微小修正逐渐消退；可选另一枚短暂尝试后归稳；布边保持静止。
- 机位：近景/微距；定格于已立鸡蛋；浅景深；硬切；曝光/对焦锁定。
- 物理：阴影短直；微摆<1°且缓慢回稳；风可略；接触斑保持居中。
- 细节：木纹与毛孔包浆可见；布边静止。

36.0–48.0s（段 D —— 收束：稳定定格）
- 画面：定格已立鸡蛋（或多枚）；可轻微前推（<3%）；加入素布折痕纹理；最后一帧干净。
- 机位：近景定格；曝光/对焦锁定；无特效；白平衡稳定。
- 物理：阴影几何一致；风量极小；尾段无手部动作（≥2 s）。
- 结尾：干净停止。
