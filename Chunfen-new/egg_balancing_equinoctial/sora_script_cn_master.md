# 春分 · 立蛋（近午顶光）— 母版 ~48s，纯画面

目标（最终策略）：约48秒母版参考（生成阶段静默、无屏幕文字）。按四段生成（12s + 12s + 12s + 12s）。不使用入/退场特效；分镜之间硬切。风格复古；物理遵循真实光/风/阴影。本习俗将光源改为近正午顶光，以符合春分立蛋的实践。

全局设置
- 画幅：16:9；总时长：约48秒。
- 风格：复古半写实；素净桌面；低饱和。
- 环境：简素院落/桌面；时期陶碗/素布；避免现代塑料/亮光漆。
- 镜头：三脚架稳定；曝光锁定；固定对焦；微距范围约15–40 cm；无变焦/无拉焦/无自动构图；仅硬切；白平衡稳定。
- 光与风：近午顶光；物体下短且直的阴影；风向右→左（0.2–0.3 m/s）；阴影极短但保持一致。
- 安全：无入退场特效；避免对焦 hunting 与曝光脉动；避免稳定器形变伪影。
- 文本与配音：生成阶段忽略（纯画面）；时间点仅供后期参考。

时间线与分镜（0.0–48.0s）
0.0–12.0s（段 A —— 准备：鸡蛋与桌面）
- 画面：摆放白胖鸡蛋；检查木纹；选择平整处；素布擦拭；展示短直阴影。
- 机位：近景/微距；对焦20–30 cm；曝光锁定；硬切。
- 物理：顶光产生短阴影长度≈1–2 cm；风0.2–0.3 m/s使布边轻动；阴影方向极小偏移。
- 细节：避免现代印刷；桌面亚光。

12.0–24.0s（段 B —— 指尖轻旋与尝试平衡）
- 画面：指尖轻旋鸡蛋；出现微小摆动；寻找平衡；接触斑极小。
- 机位：微距聚焦接触点；对焦15–25 cm；曝光锁定；无拉焦。
- 物理：接触斑直径≈3–5 mm；摆幅≈2–4°；约2 s内阻尼；风量极小。
- 细节：指甲自然；无饰品。

24.0–36.0s（段 C —— 达成立蛋）
- 画面：鸡蛋直立；微小修正；旁侧另一枚尝试失败后归稳。
- 机位：近景/微距；定格于已立的鸡蛋；浅景深；硬切。
- 物理：阴影短而直；微摆<1°；风可略。
- 细节：桌面木纹可见；布边保持静止。

36.0–48.0s（段 D —— 收束：稳定定格）
- 画面：定格已立鸡蛋（或多枚）；轻微前推（<3%）；最后一帧干净。
- 机位：近景定格；曝光/对焦锁定；无特效。
- 物理：阴影几何一致；风量极小；干净收尾。
- 结尾：干净停止。
