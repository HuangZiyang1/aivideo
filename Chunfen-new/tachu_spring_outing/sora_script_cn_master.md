# 春分 · 踏春（踏青赏花/竹篮/放风筝）— 母版 ~54s，纯画面

目标（最终策略）：约54秒母版参考（生成阶段静默、无屏幕文字）。按四段生成（15s + 15s + 12s + 12s）。不使用入/退场特效；分镜之间硬切。风格复古；物理遵循真实光/风/阴影。与分段约束同步，便于审阅与生成。

全局设置
- 画幅：16:9；总时长：约54秒。
- 风格：复古半写实；低饱和土色；清晨薄雾。
- 环境：乡野小路、草甸花丛、风筝场、简素野餐桌；竹篮、素布与器物合乎时代；避免现代塑料/亮光漆。
- 镜头：三脚架稳定；曝光锁定；固定对焦；微距范围约20–60 cm；无变焦/无拉焦/无自动构图；仅硬切；白平衡稳定。
- 光与风：右侧清晨侧光；风向右→左（0.3–0.5 m/s）；阴影一致；花瓣/草叶按物理响应。
- 安全：无入退场特效；避免对焦 hunting 与曝光脉动；避免稳定器形变伪影。
- 文本与配音：生成阶段忽略（纯画面）；时间点仅供后期参考。
