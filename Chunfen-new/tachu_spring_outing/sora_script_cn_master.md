# 春分 · 踏春（踏青赏花/竹篮/放风筝）— 母版 ~54s，纯画面

目标（最终策略）：约54秒母版参考（生成阶段静默、无屏幕文字）。按四段生成（15s + 15s + 12s + 12s）。不使用入/退场特效；分镜之间硬切。风格复古；物理遵循真实光/风/阴影。与分段约束同步，便于审阅与生成。

全局设置
- 画幅：16:9；总时长：约54秒。
- 风格：复古半写实；低饱和土色；清晨薄雾；表面亚光；器物具时间抛光痕迹。
- 环境：乡野小路、草甸花丛、风筝场、简素野餐布/桌；竹篮、粗棉/亚麻素布、陶木器物；禁止现代塑料/亮光漆；开场草叶上可见露珠（直径1–2 mm）。
- 镜头：三脚架稳定；曝光锁定；固定对焦；微距约20–60 cm；无变焦/拉焦/自动构图；仅硬切；白平衡稳定；避免数码锐化晕圈。
- 光与风：右侧清晨侧光；风右→左（0.3–0.6 m/s，随段变化）；阴影落左且清晰；无热空气扭曲。
- 安全：无入退场特效；避免对焦 hunting/曝光脉动；避免防抖形变；人与自然互动轻柔。
- 文本与配音：生成阶段忽略（纯画面）；时间点供后期参考。

时间线与分镜（0.0–54.0s）
0.0–15.0s（段 A —— 出发：小路与竹篮）
- 画面：草叶带露珠启程；竹篮与素布随行；脚步扬起微尘（粒径50–150 µm）；3–6片花瓣向左飘。
- 机位：胸口高度中广景；硬切至篮缘/编织近景（微距30–50 cm）；曝光/对焦锁定。
- 物理：风0.3–0.5 m/s右→左；花瓣飘≈0.25 m/s；草叶弯折角≈10–18°；阴影落左且边缘清晰；露珠轻颤不滚动。
- 细节：竹编间距≈6–10 mm；竹篾有轻微磨痕/包浆；素布粗织≈8–12根/cm；避免现代运动鞋与塑料饰件。

15.0–30.0s（段 B —— 赏花微距）
- 画面：花朵微距；可见花粉颗粒（50–100 µm）薄覆花药；指尖轻抬花瓣、不摘取；一只瓢虫可缓行叶面（约0.01 m/s）不受打扰。
- 机位：微距/近景交替；对焦≈20–40 cm；曝光锁定；硬切；无拉焦。
- 物理：微风令花瓣抬角≈8–14°；花粉多静止；阴影一致；草尖轻颤，微振周期≈0.9–1.3 s。
- 细节：手部最小动作；指甲自然；避免现代饰品；竹篮纹理在背景浅虚化；无蜂翼形变伪影。

30.0–42.0s（段 C —— 放风筝）
- 画面：风筝上升；线绷紧；线轴旋转；袖/绸带随风；竹骨接口可见；纸面有纤维夹杂。
- 机位：中景并插入线轴微距；曝光/对焦锁定；无甩镜；插入指尖握持与清漆磨损细节。
- 物理：风0.4–0.6 m/s；线垂度极小；线轴转速≈60–90 RPM；俯仰周期≈1.4–1.6 s；绸带右→左拖曳；线与地面夹角≈35–50°；指尖张力平稳无突抖。
- 细节：木质线轴有旧漆包浆与细划痕；麻线扭距≈8–12 mm；避免塑料部件。

42.0–54.0s（段 D —— 休憩野餐）
- 画面：铺素布，保留柔软折痕记忆；简素茶食；开篮取物；花瓣飘落；茶面出现轻微同心波纹。
- 机位：中景→近景；定格桌面陈设；硬切至成品摆盘；木纹浅景深。
- 物理：碎屑粒径≈2–6 mm；蒸汽≈0.4–0.6 m/s并偶发增强团；杯沿冷凝约1–2滴/分钟；阴影向左一致。
- 结尾：干净定格；无退场特效；避免手遮挡关键物件。
