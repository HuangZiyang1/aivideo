# 段 B — 15s — 赏花微距（纯画面）

目标：微距观察花朵与轻柔互动；不摘取。

全局设置
- 风格：复古半写实；草甸花丛。
- 环境：野花；竹篮相邻；避免现代饰品。
- 镜头：微距/近景交替；手动对焦20–40 cm；曝光锁定；硬切；无拉焦。
- 物理：右侧光；风右→左（0.3–0.4 m/s）；花瓣抬角≈8–14°；阴影一致。
- 安全：手部动作最小化；不伤昆虫。

时间线（0.0–15.0s）
0.0–3.0s（微距花瓣）：花瓣表面纹理；花粉可见；轻微抬起。
3.0–7.8s（近景花蕊）：花蕊细节；花粉静止；微风推动花瓣。
7.8–12.0s（近景指尖）：指尖轻抬花瓣；不摘；保持对焦。
12.0–15.0s（微距定格）：定格花朵细节；曝光稳定；干净收尾。
