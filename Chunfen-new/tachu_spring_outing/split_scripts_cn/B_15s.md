# 段 B — 15s — 赏花微距（纯画面）

目标：微距观察花朵与轻柔互动；不摘取。

全局设置
全局设置
- 风格：复古半写实；草甸花丛；纹理亚光；自然包浆。
- 环境：野花可见花粉颗粒（50–100 µm）；竹篮背景浅虚化；避免现代饰品。
- 镜头：微距/近景交替；手动对焦20–40 cm；曝光锁定；硬切；无拉焦；纹理浅景深。
- 物理：右侧光；风右→左（0.3–0.4 m/s）；花瓣抬角8–14°；草尖微振周期0.9–1.3 s；阴影一致。
- 安全：手部动作最小化；不伤害昆虫；手部干净自然。

时间线（0.0–15.0s）
时间线（0.0–15.0s）
0.0–3.0s（微距花瓣）：花瓣绒感纹理；花粉颗粒（50–100 µm）薄覆花药；轻抬。
3.0–7.8s（近景花蕊）：花丝细节；花粉多静止；微风令花瓣抬角8–14°。
7.8–12.0s（近景手指）：手指轻抬花瓣；不摘取；对焦≈25–30 cm；一只瓢虫可缓行（≈0.01 m/s）不受干扰。
12.0–15.0s（微距定格）：定格花朵细节；曝光稳定；干净收尾；无翼动形变伪影。
