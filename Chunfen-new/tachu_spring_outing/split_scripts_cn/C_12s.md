# 段 C — 12s — 放风筝（纯画面）

目标：呈现线张力、线轴旋转与风筝俯仰周期；无文字/无配音。

全局设置
- 风格：复古半写实；田野氛围。
- 环境：合时代线轴与风筝线；避免塑料件。
- 镜头：中景与线轴微距插入；曝光/对焦锁定；无甩镜；硬切。
- 物理：右侧光；风右→左（0.4–0.6 m/s）；线垂度极小；线轴转速≈60–90 RPM；风筝俯仰周期≈1.5 s；绸带右→左拖曳。
- 安全：阴影方向一致；保持安全取景。

时间线（0.0–12.0s）
0.0–3.2s（中景）：风筝上升；袖子随风响应。
3.2–7.6s（微距）：线轴旋转；线绷紧；转速提升。
7.6–12.0s（中景）：风筝俯仰摆动；绸带拖曳；稳定收尾。
