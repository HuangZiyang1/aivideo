# 段 C — 12s — 放风筝（纯画面）

目标：呈现线张力、线轴旋转与风筝俯仰周期；无文字/无配音。

全局设置
全局设置
- 风格：复古半写实；原野氛围；纸面纤维可见、亚光。
- 环境：木质线轴有旧漆与细划痕；麻线扭距≈8–12 mm；避免塑料件。
- 镜头：中景并插入线轴/握持微距；曝光/对焦锁定；无甩镜；硬切；加入表面纹理细节。
- 物理：右侧光；风右→左（0.4–0.6 m/s）；线垂度极小；线轴≈60–90 RPM；俯仰周期≈1.4–1.6 s；绸带右→左；线与地面夹角≈35–50°。
- 安全：阴影方向一致；安全取景；手部无突然抖动。

时间线（0.0–12.0s）
0.0–3.2s（中景）：风筝上升；袖子随风响应。
3.2–7.6s（微距）：线轴旋转；线绷紧；转速提升。
7.6–12.0s（中景）：风筝俯仰摆动；绸带拖曳；稳定收尾。
时间线（0.0–12.0s）
0.0–3.2s（中景）：风筝上升；袖子随风；竹骨接口偶露。
3.2–7.6s（微距）：线轴旋转；绷紧；转速提升；清漆磨损与细纹理可见。
7.6–12.0s（中景）：俯仰摆动≈1.4–1.6 s周期；绸带拖曳；稳定收尾。
