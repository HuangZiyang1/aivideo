# 春分 · 咬春（尝新应春）— 母版 ~54s，纯画面

目标（最终策略）：约54秒母版参考（生成阶段静默、无屏幕文字）。按四段生成（15s + 15s + 12s + 12s）。不使用入/退场特效；分镜之间硬切。风格复古；物理遵循真实光/风/阴影。与分段稿的约束同步，便于审阅与生成。

全局设置
- 画幅：16:9；总时长：约54秒。
- 风格：复古半写实；低饱和土色；清晨薄雾。
- 环境：早春市集、家中简素厨房、院内餐桌；器物与服饰合乎时代；避免现代包装/塑料/亮光漆。
- 镜头：三脚架稳定；各镜头锁定曝光与对焦；微距对焦范围约20–60 cm；无变焦/无拉焦/无自动构图；仅硬切；白平衡稳定。
- 光与风：右侧清晨侧光；风向右→左（0.2–0.4 m/s）；阴影统一落左；蒸汽/烟气按物理响应。
- 安全：无入退场特效；避免对焦 hunting 与曝光脉动；避免稳定器形变伪影。
- 文本与配音：生成阶段忽略（纯画面）；时间点仅供后期参考。

时间线与分镜（0.0–54.0s）

- 画面：摊位摆放春韭、紫红香椿芽、竹笋、白萝卜；一叠春卷皮；秤盘称重；纸包随风轻响。
- 机位：胸口高度中广景；硬切至微距/近景；曝光锁定；微距手动对焦30–60 cm；无变焦/无拉焦。
- 物理：风右→左（0.2–0.4 m/s）令皮边翘起12–18°（摆动周期≈1.2 s）；韭叶摆幅A≈0.2–0.3 m/s；阴影落左。
- 细节：避免现代印刷标签；以素纸或布袋；秤与钱币合时。

- 画面：冲洗春韭；剥竹笋；萝卜薄切；香椿芽短焯；春卷皮叠放。
- 机位：微距/近景交替；呈水滴、切面与纤维；曝光锁定；微距对焦约30–40 cm、近景约60–80 cm；无拉焦。
- 物理：水滴直径≈2–4 mm；随风右→左偏移；刀入干净；焯水蒸汽低量；阴影一致。
- 细节：布巾按压吸干；木案留刀痕；避免不锈钢高光与塑料。

- 画面：锅中油光渐起；春韭蛋/香椿炒蛋；萝卜清炒；春卷卷制准备。
- 机位：中景并插入油光与蒸汽微距（高光≈0.3→0.4）；曝光锁定；微距对焦约20–30 cm；无拉焦。
- 物理：蒸汽上升速率≈0.6 m/s后扩散；气泡直径≈1–3 mm；风右→左令蒸汽尾偏移；阴影一致。
- 细节：竹铲、锅体有岁月包浆；避免现代灶具特征。

- 画面：素器皿装盘；简素合餐；春卷或韭菜菜肴第一口；碎屑落下；轻微蒸汽。

- 物理：碎屑受重力并略向左偏移；碎屑粒径≈2–6 mm；蒸汽缕缕≈0.4–0.6 m/s；阴影一致。
- 结尾：定格成品盘；无退场特效。
