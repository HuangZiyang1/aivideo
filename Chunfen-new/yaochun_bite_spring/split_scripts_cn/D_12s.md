# 段 D — 12s — 上桌与初尝（纯画面）

目标：以可控的碎屑/蒸汽行为呈现第一口；干净收尾。

全局设置
- 风格：复古半写实；简素合餐桌；清晨暖调。
- 环境：陶/木器皿；合时代筷子；素布台布；避免现代塑料。
- 镜头：中景→近景；曝光/对焦锁定；无变焦；硬切；无甩镜。
- 物理：右侧光；风向右→左（0.2–0.3 m/s）；碎屑受重力落下并略向左偏；碎屑粒径≈2–6 mm；蒸汽上升≈0.4–0.6 m/s。
- 安全：镜头稳定；无退场特效；阴影方向一致。

时间线（0.0–12.0s）
0.0–3.2s（中景装盘）：装盘；简素桌面布置；布纹褶皱；低量蒸汽可见。
3.2–8.4s（近景初尝）：春卷/韭菜第一口；咬合角≈30–45°；碎屑粒径2–6 mm落下，略向左漂移；蒸汽持续。
8.4–12.0s（近景定格）：成品盘近景定格；风量减弱；阴影一致；干净收尾。
