# 段 C — 12s — 烹调（纯画面）

目标：以物理一致性捕捉油光起、受控翻匀与蒸汽行为；无文字/无配音。

全局设置
- 风格：复古半写实；锅体包浆；竹铲；铸铁质感。
- 环境：简素灶台；避免现代灶具显示与按键。
- 镜头：中景并插入微距；曝光锁定；微距对焦约20–30 cm；无拉焦；硬切。
- 物理：右侧光；风向右→左（0.2–0.4 m/s）；油光高光≈0.3→0.4；气泡直径≈1–3 mm；蒸汽上升≈0.6 m/s后扩散。
- 安全：阴影一致；避免运动形变；蒸汽不夸张。

时间线（0.0–12.0s）
0.0–2.8s（微距油光）：油光起；微波纹；气泡频率爬升；高光提升至≈0.4。
2.8–7.2s（中景翻匀）：春韭蛋/香椿炒蛋快速翻匀；铲子轨迹顺畅；蒸汽尾向左；保持锅体稳定。
7.2–12.0s（近景炒/卷）：清炒萝卜；卷制春卷预炸前定型；确认曝光/对焦锁定；干净收尾。
